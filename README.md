# Website Downloader — JoseloFarias fork

Herramienta para descarga y preservación local de sitios web, mantenida por **JoseloFarias** para uso técnico, archivado y automatización controlada.

## Objetivos

- Mantener descargas reproducibles y predecibles.
- Mejorar manejo de errores, rutas, recursos y sitios complejos.
- Evitar dependencias innecesarias y comportamientos destructivos.
- Conservar atribuciones y licencia del proyecto de origen.

## Estado

Proyecto en mantenimiento y evaluación.

## Uso

```bash
git clone https://github.com/joselofarias-byte/Website-downloader.git
cd Website-downloader
```

Revise la documentación y scripts del repositorio antes de ejecutar sobre sitios externos.
